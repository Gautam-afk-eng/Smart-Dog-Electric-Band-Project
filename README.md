# 🐕 Smart Dog Electric Band

### Overview
A hardware-based smart collar prototype engineered to monitor pet activity levels and vital environmental data. Utilizing an Arduino microcontroller paired with physical sensors, this edge device tracks movement patterns to help owners ensure the health, safety, and well-being of their pets.

* **Target Hardware:** Arduino UNO / Nano
* **Sensors Integrated:** Accelerometer/Gyroscope (MPU6050), Temperature Sensor, and status LEDs.

---

### ✨ Key Features
* **Real-Time Activity Tracking:** Continuously monitors physical acceleration to determine whether the pet is resting, walking, or running.
* **Environmental Monitoring:** Tracks ambient temperature thresholds to alert owners if conditions become unsafe or overheat.
* **Efficient Edge Processing:** Features optimized low-level firmware designed to handle sensor data polling and processing directly on-chip.
